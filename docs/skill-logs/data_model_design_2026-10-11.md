## 段階記録

### Phase 1（段階1〜6）

- 実施内容: SanpoGuide の ADR-002（D-7〜D-9・D-12・D-14・D-17〜D-22）、API-002 1.2（P-10〜P-15）、API-004 1.3 と、station-format 2.1.0（`CollectionValidator`・`CollectionReferences`・`MediaStage`・`Regions`）を入力に、今の DM-001 1.2 との差分を論点 1〜10 にまとめた
- 気づいた点: 素材集の ID はチャンネルの ID と別の名前空間なので、受付用の S3 のキーは接頭辞を分ける（`intake-col/`）。チャンネルの `resourcesSize`・`media` は素材集の版で変わるので、承認時に写すのではなく公開のたびに足し合わせる
- 承認ステータス: 完了

### Phase 2（段階7〜8）

- 段階7: 開発者が論点 1〜10 をすべておすすめどおりに決めた（「おすすめで」）。アカウントに役割を持たせる、制作元は自分で有効にし身元は最初の素材集の承認で確かめる、素材集の項目は別に作り審査待ちの列は共通、上限は素材集 5・申請の回数は共通、外部の素材は申請時に流し読み・毎日は HEAD、依存は利用の記録で D-8 を 2 回確かめる、段と版の対応表、リストの値の計算、取り下げ・退会・停止

- 承認ステータス: 段階9（改訂の承認）待ち
