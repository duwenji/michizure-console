## 段階記録

- 実施内容: DM-001 1.3（M-16〜M-25、AP-23〜AP-29）を入力に、今の API-001 1.0 との差分を C-15〜C-22 にまとめ、契約書と OpenAPI（1.1.0）を改訂した。操作は、制作元 9 件（役割を有効にする、素材集の登録・一覧・取得・使っているチャンネル・申請の作成・一覧・取得・取り消し）と運用者 10 件（パッケージ、審査の記録、開始・戻す・承認・差し戻し・却下、取り下げ、アカウントの素材集）を足した
- 判断根拠: パスは変えず足すだけにした（互換性方針。配備は API → SPA）。審査待ちの一覧は共通にして `kind` で見分ける。段と版の対応表は CDK のコンテキストに置き、PR を通して変える（DM-001 未決事項 No.5 の解決案）
- 確認: OpenAPI から型を生成できた（形式の誤りなし）。生成し直した型では、既存の API・SPA に型の誤りが 3 か所出る（新しいエラーコードの HTTP の対応、上限の `collections`、審査待ちの項目が 2 種類になった）。実装の PR で直すため、生成した型はこの PR に含めない
- 承認ステータス: 承認済み（2026-10-11、開発者）
